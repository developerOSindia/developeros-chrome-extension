| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within DeveloperOS QuickTools, please do NOT disclose it publicly on GitHub Issues.

Instead, please send an encrypted or direct security report to:
- **Email**: `security@developeros.in`
- **DeveloperOS Security**: [https://developeros.in/security](https://developeros.in)

Please include:
- A description of the vulnerability and attack vector.
- Steps to reproduce or proof-of-concept code.
- Potential impact on users or data.

We acknowledge receipt of reports within 48 hours and coordinate remediation before public release.
